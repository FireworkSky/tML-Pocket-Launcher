# 安装使用指南

## 设备与资源

- Android 9 / API 28 或更高版本，arm64-v8a。暂不提供 armv7 或 x86 APK。
- 合法拥有的 Terraria 游戏资源。
- 足够的可用存储：安装过程中需要同时容纳下载包、暂存文件、安装目录和用户数据，实际用量随版本和模组变化。
- 稳定网络用于官方版本下载、商店登录和 Steam 所有权验证。

目前有真机主菜单验证记录的组合为 Terraria `1.4.4.9` + tML `2026.09.3.1`。不承诺所有 tML 版本与所有模组均可运行。

## 1. 安装启动器

使用自行构建或项目发布的 APK。开发调试构建的路径为 `android/app/build/outputs/apk/debug/app-arm64-v8a-debug.apk`。当前应用 ID 为 `app.com.tmlpocket`，外部应用专属目录为 `Android/data/app.com.tmlpocket/`。同应用 ID 和兼容签名的覆盖安装通常保留应用数据；更换签名或卸载前请先备份。

旧模板包名 `com.example.fnatemplate` 与当前版本属于两个独立应用，安装新版不会自动迁移旧版的游戏资源、存档、模组或设置。完成备份和迁移前请保留旧版。

## 2. 添加 Terraria

在“游戏”页选择导入或商店账号入口：

| 来源            | 操作与启动要求                                                                   |
| --------------- | -------------------------------------------------------------------------------- |
| Steam ZIP       | 导入完整资源包；每次启动前登录并验证当前账号拥有 Terraria                        |
| Steam 下载      | 使用 SteamKit2 登录，根据需要在设备输入 Steam Guard 验证码，下载时验证所有权，安装后可离线启动 |
| GOG Linux `.sh` | 导入 Linux 安装包并提取其中资源；不执行安装脚本，启动无需 GOG 登录               |
| GOG 下载        | 在官方授权页面登录，选择资源版本并下载；完整付费传输仍待真实账号验证             |
| Terraria PE     | 从本机已安装的游戏转换资源，完成后在首页启动。[Terraria PE 支持说明](terraria-pe.md) |

使用启动器自带的文件浏览器选取本地包，按提示授予文件访问权限。不要将存档、单独的模组包或源码压缩包当作 Terraria 资源导入。GOG 分卷包暂不支持。

## 3. 安装 tModLoader

缺少可用的 tModLoader 时，点击「准备游戏」打开版本列表，选择版本后即可下载并安装。要添加其他版本，可从 tML 版本列表下载官方发行版，或导入其完整 ZIP。

不同 tModLoader 版本独立安装。新安装的版本会成为默认实例的启动版本。其他实例可在底部「游戏实例 → 管理已安装版本」中单独指定启动版本。旧版单版本安装会自动出现在列表中，无需重新导入。

默认实例沿用原来的 `userdata/`。新实例各自保存角色、世界、模组和设置，Terraria 资源与 tML 发行文件由各实例共用。在底部的实例选择器可创建、切换或归档实例。

在「下载任务」中可排队、暂停和继续下载官方 tML 发行包。重新打开启动器后，可手动继续中断的任务。当服务器确认文件版本和下载范围仍然匹配时，启动器会从已下载的位置继续。

## 4. 管理模组

在“模组”页顶部点击“添加模组”，选择“导入游戏模组”。已安装列表支持搜索、启停、删除和批量操作。启用检查依赖，停用会处理依赖它的模组；更改在下次启动游戏后生效。

启动器随游戏加载 MobileJoystick 触控补丁。升级后，旧触控模组文件会移到 `userdata/Mods/.launcher-backup`，原配置可由补丁和启动器继续读取。

“下载模组”打开独立的 Terraria 与 tModLoader 创意工坊目录，可搜索、按分类和排序浏览、查看详情并下载。tModLoader 支持官方模组分类、版本和语言标签筛选；Terraria 支持世界与资源包标签。已登录时复用启动器的 Steam 会话，未登录时尝试匿名访问；单个项目可能受 Steam 权限限制。下载后启动器会校验并安装支持的模组、世界或资源包。真实设备上的工坊传输仍待验证。模组包 JSON 保存启用清单，不能代替缺失的游戏模组。

## 5. 启动与触控

在“设置 → 控制管理”打开全屏编辑器。悬浮菜单可切换游戏控制和游戏界面。点击画布上的控件或界面区域可编辑属性，拖动可调整位置。保存后，下次启动游戏时应用布局。编辑器和游戏使用横屏，退出编辑后恢复启动器的方向设置。

使用游戏内的性能控件切换帧率显示。120 FPS 呈现可在补丁页启用。联机托管是必要补丁，适配 tModLoader 2026.09.3.1。

## 数据与备份

在「设置 → 存储与下载 → 存档备份」可备份当前实例中的角色和世界、导入或导出 ZIP，并可开启启动前自动备份。恢复会先保存当前角色与世界的副本，再替换存档。备份 ZIP 可导出到设备的共享目录。

默认实例的数据位于 `userdata/`，新实例的数据位于 `instances/<实例 ID>/userdata/`。授予文件访问权限后，存档、模组和备份保存在共享目录，卸载启动器后仍可接回。Terraria 游戏资源和 tModLoader 发行包保存在应用私有目录。重新安装启动器后需重新添加 Terraria 游戏资源。

请不要把存档或游戏资源发到公开 Issue。反馈时提供复现步骤和已脱敏日志即可。更多问题见 [故障排查](troubleshooting.md)。
